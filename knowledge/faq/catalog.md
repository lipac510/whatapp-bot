# Catalog

## Customer questions

- Do you have a catalog?
- Can you send me your catalogue?
- Can I see pictures?
- Do you have examples?

## Short answer

Yes, we can share product examples and catalog. We currently have a luxury rigid box catalog and product example images. Please tell us which packaging product you are interested in, so we can send the most relevant catalog or pictures.

## Details

- Rigid box catalog: `knowledge/assets/catalogs/rigid-box-catalog.pdf`
- Paper bag example images are available under `knowledge/assets/images/paper-bags/`.
- Rigid box example images are available under `knowledge/assets/images/rigid-boxes/`.
- If a relevant catalog file exists, send that catalog link.
- If product is unknown, ask which product category they need.
- If product is known, send the matching catalog or images.
- Do not send unrelated catalogs if the customer's product need is clear.

## Assets

- Put catalog PDFs under `knowledge/assets/catalogs/`.
- Put product images under `knowledge/assets/images/`.

## Return prompt

If product is missing, ask: "Which packaging product are you interested in?"
